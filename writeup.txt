For the rating prediction task, I implemented a global average + user bias + book bias model
first compute the global average rating across all training data.
then compute the bias for each user as the difference between the user’s average rating and the global average.
then compute the bias for each book as the difference between the book’s average rating and the global average.f
for each (user, book) pair in the test set, predict the rating as:  
  `predicted_rating = global_average + user_bias + book_bias`  
  with the result clamped to the range 1–5.
